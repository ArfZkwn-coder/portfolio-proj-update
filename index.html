N8n Automations

Status
Ongoing — runs unattended
Built with
n8n, Telegram API

The problem

Server maintenance had to be remembered and checked by hand — routine updates and health checks only happened when someone went looking.

How it works

  • Auto-update routines run on a schedule instead of at someone's discretion.
  • Real-time server health monitoring runs continuously alongside them.
  • Health and update results are delivered as Telegram messages, so there is no dashboard to remember to open.

Outcome

Health checks and updates run unattended, with anything unusual pushed to Telegram instead of waiting for a manual check.

Case study

Personal Homelab & Game Server

Status
Ongoing
Built with
Docker, Linux, Tailscale

The problem

Self-hosted services and game servers need to stay reachable from outside the network without opening the network up to the internet.

How it works

  • A local Linux-based server environment hosts the services, with Docker keeping them isolated and reproducible.
  • Securing remote access runs over Tailscale, so connectivity stays encrypted.
  • No local ports are exposed to the public internet.

Outcome

Services are containerised and reachable remotely over an encrypted mesh, with no inbound ports published to the internet.

Stack

  • Hardware
  • Docker
  • Linux
